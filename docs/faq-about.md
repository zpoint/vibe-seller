# 了解 Vibe Seller

## 和亚马逊 SP-API 有什么区别？

SP-API 是亚马逊面向开发者的官方接口，仅适用于亚马逊：需要注册开发者并获得授权，由程序按亚马逊规定的数据格式交互，能力限于接口开放的范围。广告不在 SP-API 内，属于需要单独申请的 Amazon Ads API；账户健康、卖家支持 Case 等后台功能也没有对应接口。

Vibe Seller 由 AI 直接操作店铺浏览器，后台页面上能完成的操作都可以执行，不限平台，也不需要申请接口。

两者并不互斥。店铺绑定 [Amazon Ads API](ads-api.md) 后，广告操作走 API；未绑定的店铺，以及没有接口的操作，仍在浏览器中完成。系统按店铺的授权状态自动选择。
