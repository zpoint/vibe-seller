# 集成总览

Vibe Seller 负责调度和执行任务；进入店铺、读取邮件、发送消息、生成图片等操作，需要通过外部服务完成。这一页回答三个问题：**能接入哪些服务**、**分别在哪里配置**、**按什么思路选择**。

配置入口分三处：「设置 → 集成」（广告、API Key、群机器人、Google Workspace、滴答清单这五块，按此顺序排列）、「设置 → 邮箱」（独立标签页）、「设置 → AI」（图像生成在该页最下方）。

## 能接入哪些服务

| 集成 | 能做什么 | 在哪里设置 | 详细页 |
|---|---|---|---|
| **MCP 接入** | 让外部 AI 工具建任务、跟进、答复、审方案 | 「设置 → 集成 → API Key」 | [MCP 接入](mcp.md) |
| **Vibe Seller 广告 API 服务** | 广告读写直连接口，不点网页（仅亚马逊） | 「设置 → 集成 → Vibe Seller 广告 API 服务」，在店铺列表逐个点「授权」 | [广告 API 接入](ads-api.md) |
| **邮件（IMAP / SMTP）** | 同步收件箱，AI 查信、归类、起草、代发 | 「设置 → 邮箱」→「添加邮箱」 | [邮件接入](email.md) |
| **群机器人** | 把结果和告警发到群里，发文件仅企业微信 | 「设置 → 集成 → 群机器人」→「添加机器人」 | [群机器人](chat-bots.md) |
| **滴答清单 / TickTick** | AI 读写你的待办清单 | 「设置 → 集成 → 滴答清单 / TickTick」 | [滴答清单](ticktick.md) |
| **Google Workspace** | Sheets、Drive、Gmail、Docs、Calendar | 「设置 → 集成 → Google Workspace」→「启用」 | [Google Workspace](google-workspace.md) |
| **AI 图像生成** | 生成主图、信息图，可按参考图改图 | 「设置 → AI → 视觉（图片生成）」 | 见本页[AI 图像生成](#ai-图像生成) |

每个集成按什么范围生效、AI 能做到哪一步：

- **MCP 接入（API Key）**——按用户生效。每张 Key 代表创建它的用户，权限与本人相同，没有更细的档位；只有网页端能做的操作除外（管理用户、重新生成密钥、查看已保存的密码）。
- **Vibe Seller 广告 API 服务**——按店铺生效。一次授权一个店铺，同一店铺开通多个站点要分别授权；授权和解绑只有管理员能操作。本台安装的连接凭据由服务端在首次使用时自动下发，不需要你填写任何 Key。AI 可读写，范围限于该店铺已授权的广告账户；改动只应用在你批准过的条目上。
- **邮件（IMAP / SMTP）**——收件每 5 分钟同步到本地。邮箱账号本身由整台实例共享（添加人只是记录），再在邮箱卡片或「设置 → 店铺」关联到店铺；某个任务能看到哪些邮箱，取决于它所在店铺关联了什么。**读**：已同步到本地的邮件；**发**：由每张邮箱卡片上的「发邮件权限」开关控制，默认开启，只能由登录用户在界面上拨动，AI 无法修改。
- **群机器人（企业微信 / 钉钉 / 飞书 / Slack）**——整台实例共享，不按店铺区分；平台根据粘贴进来的 Webhook 地址自动识别。只能发不能收：AI 可以发消息、上传文件；读取群消息的能力目前尚未提供。
- **滴答清单 / TickTick**——整台实例共用一套连接；可以只指定一个默认项目，不指定时 AI 可访问你的全部项目；AI 对你自己的清单和任务可读写。
- **Google Workspace**——整台实例一个开关，所有任务共用同一份授权；在你授权过的那个 Google 账号内可读写，没有逐项开关。前提是本机已安装 gws CLI 并登录过 Google，开关只有管理员能拨。
- **AI 图像生成**——整台实例一个密钥，只有管理员能填。AI 只能按任务里的要求生成，且每次生成前都必须由你在确认卡片上点击「生成」。

## 常见场景怎么选

### 都能收邮件：选「邮件」还是 Google Workspace

- **邮件**走通用 IMAP / SMTP：任何邮箱都能接入（163、QQ、Gmail、自建邮箱都可以）。AI 读的是同步到本地的那一份，发信受「发邮件权限」开关约束，可以逐个邮箱单独设置。适合客服邮箱这种「只有一个收件箱要处理」的场景。
- **Google Workspace** 走 Google 自己的授权，装上后是一组命令行能力：不只读信，还能写文档、建日历、读表格，AI 当场调用接口取最新数据，不读缓存。代价是只有 Google 账号能用、需要在这台机器上安装 CLI，而且是整台实例一个开关，没有逐项权限可关。
- 同一个 Gmail 地址两边都能配，但两条路互不打通：一边是同步到本地的收件箱副本，一边是实时调用 Google 接口。如果只想让 AI 从一个入口处理 Gmail，就只配置一处——另一条路它照样能用。

### 一个是出口，一个是入口：群机器人和 MCP 接入

- **群机器人**朝外：任务把结果推到群里，群里的人看得到，但不能通过机器人反过来指挥 Vibe Seller。
- **MCP 接入**朝里，方向相反：你在自己手上的 AI 工具里连接进来，替你建任务、追问、答复、审方案。它使用的每张 Key 都固定对应一个用户身份，权限就是那个人本人。
- 这两条通道，与 Vibe Seller 内部 AI 执行任务使用的工具，是三套相互独立的机制。

### 走接口还是走浏览器：广告操作

- 广告本身的操作——报表、投放对象、搜索词、改价改预算——走 API 比让 AI 一格一格点网页快得多，也稳定得多（[广告 API 接入](ads-api.md) 里那组 147 分钟 → 11 分钟的实测对比就是这个差别）。
- 卖家后台里与广告无关的部分——优惠券、报表下载、绩效与审核、类目相关操作——只有网页上有，仍要走店铺浏览器。没有授权广告 API 的店铺，AI 会退回用浏览器操作后台的方式。

### 按店铺、按用户，还是整台实例共用

- **按店铺生效**：浏览器后端及其档案（紫鸟账号或 Chrome 持久档案，见 [店铺与浏览器](stores.md)）、亚马逊广告授权、店铺关联的邮箱。
- **按用户生效**：API Key（MCP 接入）。
- **整台实例共用**：邮箱账号、群机器人、滴答清单 / TickTick、Google Workspace、图像生成的密钥。
- 实际影响：换一个人登录，API Key 要自己重新创建；但邮箱、机器人、清单、Workspace、出图密钥是整台机器共用的一套。广告授权记在店铺上、不记在人上，而且只有管理员能授权或撤销——所以两个人共用一个店铺时，这个店铺授权一次就够，但要由管理员来点。

## AI 图像生成

**能做什么**：在任务里，AI 可以提出“给这个产品出一张场景图”，或者“照着这张参考图换背景”。背后走 kie.ai 的统一接口（Nano Banana 一类的模型），一个密钥能用到目录里的所有模型。

**在哪里配置**：「设置 → AI」页面最下方的「视觉（图片生成）」，旁边有状态标记「未配置」/「已配置」（后面带密钥末四位）。把 kie.ai API 密钥填进掩码输入框，点「保存」。**密钥只有管理员能填**，普通用户在这一块看到的是「仅管理员可设置视觉 API 密钥。」界面上的说明原文是：「kie.ai API 密钥，用于 AI 商品图生成（Nano Banana）。配置后 agent 才能生成主图或信息图。」

**不配会怎样**：出图这件事对 AI 就是不可见的——它手里没有这个工具，任务里需要图片时，只会提示你去这个页面配置。这个页面也只有密钥一项：模型不在这儿选，价格也不在这儿看，这些都放在下面那张确认卡片上。

**每一步都要你确认**：AI 只能提议，不能自己把图生成出来。流程是：AI 提出提示词和模型 → 对话里出现一张「确认图片生成」卡片，提示词可以改（「提示词（生成前可编辑）」）、模型可以换（「模型」）、可以附参考图（「参考图」），卡片上还写着这张图大概多少钱 → 你点「生成」才会真正开始（此时提示「正在生成图片…大约需要 1–2 分钟」）；点「取消」则什么都不生成，也不花钱。最终以你改过的提示词和模型为准，不是 AI 原来那份。生成好的图贴在任务流里（「生成的图片」），同时保存在这个任务的工作区。这个确认由服务端强制执行，与任务处于「自动」还是「先审核」模式无关。

**边界**：这个功能只会生成新文件，不会修改磁盘上已有的原图——AI 要改动你本地那张图，得另走文件那条路。

> 开发向的细节（接口、模型目录、同步、价格）写在 [开发者文档的图像生成一节](vision.md)。

## 一个任务里同时用几个集成

集成之间互不冲突，常见用法是把几个集成叠在同一条任务里。比如一个周一早上的定时任务：

> “看一下店铺A过去一周的买家来信，把差评和退款诉求整理出来；涉及在投广告的 SKU 去广告后台对一下这个搜索词的花费和转化；结论推到企微群，要跟进的记进滴答清单。”

这一条任务依次用到：店铺关联的**邮箱**（读）→ **广告 API**（用这个店铺自己的授权查数）→ **群机器人**（把结论发到群里）→ **滴答清单**（写待办）。

能叠用哪些取决于任务的范围：绑定了店铺的任务，可以用这个店铺的浏览器、广告授权和关联邮箱；「全部店铺」的任务只有通用浏览器加上那套共享集成（邮件、群机器人、滴答清单、Google Workspace、图像生成），进不了任何一家店铺的后台。
