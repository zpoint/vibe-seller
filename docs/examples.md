# 使用示例

每个示例都是一件卖家会反复做的事。页面从「在哪里点」写到「跑完长什么样」，
每一步配一张界面截图，描述文字可以直接复制粘贴。不需要先读完其他文档。

开始之前，这台机器上要有：一个能用的 AI 配置、至少一个店铺。
还没有的话，先看[快速开始](quickstart.md)。

## 五个示例

- [每天检查邮箱，把需要关注的邮件发到企业微信群](example-email-wecom.md)
  早上不用先翻收件箱：需要回复的、供应商和平台通知、不用管的，三类分好，
  每封带一句建议动作，09:00 进群。设置约 10 分钟。

- [每周检查广告，ACOS 超过 30% 的给出优化方案并提醒](example-ads-acos.md)
  每周一早上出一份 ACOS 超线的清单，写明花费、订单和建议；改动要你确认，
  确认后它才动广告账户。设置约 15 分钟。

- [每周巡检所有店铺的 Listing](example-listing-check.md)
  一次触发，每家店各跑一个任务，把被下架、被抑制、缺主图缺规格的条目按店铺
  列出来，最后合一份总清单。设置约 5 分钟。

- [每天把前一天的销售报表导出来，发到群里](example-daily-report.md)
  每天固定时间导出昨天的销售数据，CSV 存进任务文件，摘要和文件一起进群。
  设置约 5 分钟。

- [在 Codex 里分析店铺近 3 个月的财务数据](example-mcp.md)
  在 Codex 里说一句，Vibe Seller 用紫鸟打开店铺A，下载过去 3 个月的月度交易报表；
  Codex 取回后按月算出销售额、各项费用、退款和净到账。设置约 5 分钟。

## 这些示例用到的能力

| 能力 | 在这里做什么 | 在哪里设置 | 详细文档 |
|---|---|---|---|
| 定时任务 | 到点自动建任务，每次照同一份计划执行 | 侧栏「任务」→ 定时 | [定时任务](schedules.md) |
| 邮箱 | AI 读信、归类、起草，按邮箱决定是否允许发送 | 「设置 → 邮箱」 | [邮件接入](email.md) |
| 群机器人 | 把结论和文件发到群里（只出不进） | 「设置 → 集成 → 群机器人」 | [群机器人](chat-bots.md) |
| 广告 API | 广告数据直连接口，不用一格一格点网页 | 「设置 → 集成 → 广告 API 服务」 | [广告 API 接入](ads-api.md) |
| API Key | 让外部 AI 工具连进来操作这台服务器 | 「设置 → 集成 → API Key」 | [MCP 接入](mcp.md) |

同一个任务里可以叠用好几项。比如周一早上那条广告巡检，读的是店铺关联的邮箱、
查的是这家店自己的广告授权、发的是共享的群机器人。各集成分别归谁管
（店铺、人，还是这台机器），见[集成总览](integrations.md)。

## 示例里没有的事

- 群机器人只能往外发，读群消息这条链路还没接：AI 看不到群里别人说了什么。
- 任务不会自动往群里推通知，只有你在描述里要求、或者你事后追一句，它才发。
- 广告改动一定经过你确认；Listing 巡检只报告问题，改不改由你说。
