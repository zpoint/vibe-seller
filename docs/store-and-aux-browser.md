# 店铺浏览器与辅助浏览器

这是 Vibe Seller 的浏览器设计：防关联店铺（紫鸟 / 悦互联）的任务同时有两个浏览器可用，各管一摊。

| | 店铺浏览器（主，紫鸟 / 悦互联） | Chrome 辅助浏览器 |
|---|---|---|
| 用来做什么 | 卖家后台：上架、改库存、看报表、改广告 | 卖家后台之外的网页：物流轨迹查询、海外网站、搜索引擎、供应商网站、产品前台页面 |
| 长处 | 指纹和 IP 隔离，保存着店铺的登录状态，登录卖家后台最安全 | 不受限制，什么网站都能打开 |
| 限制 | 能打开的网站有限，很多海外网站、物流网站打不开 | 没有登录卖家账号，**不会**用来操作卖家后台 |

防关联浏览器保护店铺账号，但限制也多；Chrome 正好补上它打不开的那些网站，两者相辅相成。
比如任务要「核对订单的物流状态」：订单信息在店铺浏览器里从卖家后台读，物流轨迹在 Chrome
里查承运商网站，结果合在同一份报告里。

这些都是自动的：辅助浏览器在第一次用到时才启动，每家店各一个、互不共用，公开网站的
Cookie 在任务之间保留。哪个网址走哪个浏览器由 AI 判断，你不需要选择；想固定某些网址
的走法，可以在这家店目录下的 `browser-routing.md` 里写规则，它会优先于默认规则。

Chrome 店铺本身就是普通 Chrome，没有这些限制，只用一个浏览器。

支持哪些浏览器、怎么选，见 [浏览器总览](browsers.md)。
