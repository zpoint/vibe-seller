## Report a problem or suggest a feature

[Open a GitHub issue](https://github.com/zpoint/vibe-seller/issues/new), or first [search the existing issues](https://github.com/zpoint/vibe-seller/issues) to see whether someone already hit the same thing. You can also post in the user groups.

## What to include in a report

The more complete the report, the faster it gets fixed:

1. **Version** — shown next to "Vibe Seller" at the top-left of the web UI, e.g. `v0.3.1`.
2. **System** — macOS, Linux, the Windows installer, or Windows + WSL2.
3. **What you did, what you expected, what happened** — e.g. "I picked Ziniao when creating a store, clicked Create, and saw …".
4. **Screenshots** — the error message and the task detail page.
5. **Logs** (optional) — server logs live in `~/.vibe-seller/logs/`, e.g. `backend_7777.log` (on Windows: `C:\Users\<you>\.vibe-seller\logs\`).

Common problems such as Ziniao binding errors may already have a fix — check the [FAQ](faq.md) first.
