# 费用与模型选择

## 要花多少钱？

Vibe Seller 本身免费开源，需要付费的只有你自己的 LLM API Key——直接付给供应商，没有中间商。

用量参考：用 DeepSeek 执行一次广告调优，10 组广告以内大约 1 元人民币，整个任务耗时 3 到 5 分钟。广告越多、页面越多，花费越多。想控制成本，可以把例行任务交给便宜的档位，复杂任务再使用旗舰模型，见下面「该选哪个 LLM」。

## 该选哪个 LLM？

同时满足两个条件的模型才适合：**上下文长**、**能看图（多模态）**。例如 GLM-5.3-Flash，在「设置 → AI」的模型下拉框里同时标着「1M 上下文」和「视觉」。AI 需要看页面截图判断当前状态，纯文本模型在浏览器自动化上表现会明显变差，因此下拉框里的「视觉」和「纯文本」标记不要选错。

按任务难度选择档位：

| 任务类型 | 建议档位 |
|---|---|
| 复杂任务 | 各家的旗舰模型 |
| 简单任务 | Flash 或便宜档位即可 |

复杂任务指探索新平台（没有内置 Skill）、广告优化、库存策略、跨页面长流程；简单任务指邮件分类、固定流程数据抽取、按字段填表。

复杂任务里，AI 要一边读取 Skill、一边判断页面状态、一边调用工具、一边记录笔记，能力不足的模型容易跳过步骤、填错工具参数、忘记前面的判断。一次失败的复杂任务消耗的 token 和时间，比直接用旗舰模型一次完成还要多。简单任务用哪个模型差别不大，能省则省。

各家 Key 怎么获取、该选哪个预设，见 [配置 AI 模型](llm-keys.md)。
