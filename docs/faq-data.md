# 部署与数据

## 能部署在云服务器上吗？

可以，但浏览器需要有地方渲染画面。Vibe Seller 服务本身在无图形界面的服务器上运行没有问题；紫鸟（以及你希望看着它操作的 Chrome 后端）需要一个能输出画面的环境——虚拟显示（Xvfb）、云桌面虚拟机，或者用 VNC 进入一个真实的图形会话都可以。

更省事的做法是在本地放一台长期开机的小机器——Mac mini、装了 WSL 的迷你 Windows 主机，或一台闲置笔记本——团队通过内网连接使用。配置开机自动启动、崩溃后自动拉起，见 [安装](install.md#让它一直开着)。

## 我的店铺数据会不会泄露？

不会上传到任何云端。数据库、截图、日志、店铺记忆全部在你硬盘的 `~/.vibe-seller/` 目录里（Windows 上就是 `C:\Users\<你的用户名>\.vibe-seller`），没有云端存储，也不需要注册账号。

离开你机器的流量只有两类：

1. **发给 LLM 供应商的 Prompt**——包含 AI 读取到的页面内容，这是让 AI 工作必须付出的代价，你使用哪家供应商就受哪家隐私条款约束；
2. **匿名使用上报**——只发送安装信息和任务计数，**不含任何店铺内容**。默认开启，可以在「设置 → 通用」里关闭「匿名使用数据上报」，或者设置环境变量 `VIBE_SELLER_TELEMETRY=0`。

除此之外不向外部发送任何内容。紫鸟等凭据存在哪里、界面上谁能看到，见 [凭据存在哪里](ziniao.md#凭据存在哪里)。

## AI 的记忆存在哪？

全部是纯 markdown 文件，没有任何内容锁在程序里。每个店铺的知识积累在 `~/.vibe-seller/stores/<店铺标识>/` 下面，你可以查看、修改，也可以在不同机器之间拷贝；跨店铺共用的经验在 `~/.vibe-seller/knowledge/`；Skill 同样是 markdown，在 `~/.vibe-seller/.claude/skills/`。

也不需要手工去翻这些文件：网页里的「知识库」页签可以直接查看和编辑这些文件，还能通过对话让 AI 帮你整理进去。目录结构和写法见 [知识库与 Skill](knowledge.md)。

## 为什么界面上有些按钮是英文的？

因为那几处还没有做翻译，中文和英文界面显示同一串英文：「Create & Run」（创建任务的确认按钮）、「Chrome (Playwright)」（浏览器后端选项）、「Add account」（紫鸟账号旁边的加号）、「Claude Code CLI」（设置里的后端名称）。文档里提到这些按钮时一律按照界面上的原样书写，看到英文不用怀疑自己走错了地方。
