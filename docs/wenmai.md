# 稳卖：配置指南

稳卖（WenMai）是一款电商防关联浏览器（[官网](https://www.wenmai-ai.com)）。绑定后，Vibe Seller 会自动打开并登录稳卖客户端，再用它打开你的店铺执行任务，不需要你手动操作客户端。

**稳卖后端支持 Windows、macOS，也支持 WSL**。

不用稳卖的话，这一页可以跳过。Vibe Seller 还支持其他浏览器，见 [浏览器](browsers.md)。

## 下载与安装

1. 打开稳卖官网 <https://www.wenmai-ai.com>，下载对应系统的客户端（Windows / Mac）并安装。装在哪个目录都可以，Vibe Seller 会自己找到它。
2. 安装后至少手动启动并登录一次稳卖客户端，确认账号正常、能看到你的店铺列表。之后 Vibe Seller 会自动拉起并自动登录这个客户端。

## 创建企业账号（并授权店铺）

稳卖用「企业登录」：企业名称 + 企业用户名 + 企业密码。**手机号登录不支持**，请使用企业登录。

1. 在稳卖客户端里用管理员账号进入 **团队管理 → 成员**，创建一个企业子账号。
2. 在 **店铺权限** 里勾选这个子账号可以操作的店铺。子账号只能看到授权给它的店铺——一个都没授权，它在 Vibe Seller 里就一个店铺都列不出来。如果设备（网络环境）也需要单独授权，同样在这里给它勾上。
3. 记下三样东西：**企业名称**、**企业用户名**、**该用户的密码**。这就是你在 Vibe Seller 里要填的。

## 给店铺绑定设备

稳卖里每个店铺都要绑定一个设备（网络环境）才能打开。没绑定设备的店铺会出现在列表里，但显示为「未绑定设备」、无法选中——去稳卖客户端给这个店铺绑定设备后刷新即可。

!!! warning "店铺要用 Chrome 内核"

    店铺的浏览器内核要选 **Chrome**：Firefox 等其他内核的店铺任务打不开，见 [店铺要用 Chrome 内核](browsers.md#店铺要用-chrome-内核)。

## 绑定时要填什么

新建店铺时浏览器后端选「稳卖」，和紫鸟在同一个表单里绑定：

1. 点账号栏右侧的「+」，填写三项并保存：

| 字段 | 是什么 |
|---|---|
| 企业名称 | 你的稳卖企业标识 |
| 企业用户名 | 企业下那个子账号的用户名 |
| 企业密码 | 该子账号的密码 |

2. 保存后，Vibe Seller 会用这套企业登录自动登录客户端，并自动加载这个账号能看到的店铺列表。客户端退出了、或登录过期了，也会自动登回去，任务不会因为「没登录」而中断。
3. 在「选择店铺...」里挑出这家店对应的那一个，点「创建」。列表显示「店铺名 · 平台」；未绑定设备的店铺是灰的、选不了。

## 一台机器只支持一个账号

和悦互联一样，一台机器同一时间只能登录一个稳卖账号，所以账号栏**只有一个「+」**，没有编辑 / 删除——再点「+」填一个新账号，就会**覆盖**原来那个。

如果这台机器上已经绑了稳卖店铺，直接加新账号会被拦下（见下面「常见提示 / 报错」里的对应提示）。要换成另一个稳卖账号：先在「设置 → 店铺」里删掉所有稳卖店铺，再点「+」添加新账号、重新绑定店铺。同一台机器上的所有稳卖店铺都共用这一个账号。

## 常见提示 / 报错

<details id="middle-page">
<summary>打开店铺时出现「店铺信息」中间页</summary>

不用管——Vibe Seller 会自动点「打开店铺」进入真正的店铺后台。
</details>

<details id="closed-mid-task">
<summary>任务进行中关掉了稳卖 / 手动打开过店铺</summary>

不用处理：下次用到浏览器时会自动重开客户端并登录；手动打开的店铺会被直接接上，任务结束后正常关闭。
</details>

<details id="not-logged-in">
<summary>提示未登录</summary>

没配企业登录、或自动登录没成功。确认「+」里填的企业名称 / 用户名 / 密码正确，且客户端能手动登上，再点「刷新」。
</details>

<details id="cannot-start">
<summary>提示无法启动稳卖客户端</summary>

Vibe Seller 没找到 / 没能拉起客户端。先手动打开稳卖客户端，或按上面「下载与安装」确认已装好，再点「刷新」。
</details>

<details id="no-device">
<summary>店铺列表里有灰色、选不了的行</summary>

这个店铺在稳卖里没绑定设备（显示「未绑定设备」）。去稳卖客户端给它绑定设备后刷新。
</details>

<details id="firefox-kernel">
<summary>店铺用了 Firefox 内核，任务打不开</summary>

这个店铺在稳卖里用的是 Firefox 内核，任务打不开。在稳卖客户端把它切换为 Chrome 内核。
</details>

<details id="one-account">
<summary>想换一个稳卖账号</summary>

见上面「一台机器只支持一个账号」：先删除所有稳卖店铺，再添加新账号。
</details>

<details id="unsupported-platform">
<summary>不支持的平台</summary>

稳卖后端支持 Windows、macOS，也支持 WSL。
</details>

<details id="where-credentials">
<summary>凭据存在哪里</summary>

企业登录（企业名称 / 用户名 / 密码）保存在你本地的 `~/.vibe-seller/data/vibe_seller.db`（SQLite）。密码加密存储，只在自动登录那一刻才在内存里解密；接口不会把密码返回给前端。因为一台机器只有一个稳卖账号，这套凭据是机器级的，所有稳卖店铺共用。想看具体加密实现见 [开发者指南](dev-guide.md)。
</details>
