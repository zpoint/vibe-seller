# 稳卖：配置指南

稳卖（WenMai）是一款电商防关联浏览器（[官网](https://www.wenmai-ai.com)）。绑定后，Vibe Seller 会自动打开并登录稳卖客户端，再用它打开你的店铺执行任务，不需要你手动操作客户端。

**稳卖后端支持两种运行方式**：Windows（推荐，服务器和浏览器都直接跑在 Windows 上）和 WSL（在 Windows 里跑 WSL 的用户也可用，稳卖客户端仍在 Windows 侧）。macOS 支持正在验证中；纯 Linux 上不可用——稳卖客户端本身只有 Windows 和 Mac 版。

不用稳卖的话，这一页可以跳过。Vibe Seller 还支持其他浏览器，见 [浏览器](browsers.md)。

## 下载与安装

1. 打开稳卖官网 <https://www.wenmai-ai.com>，下载 Windows 客户端并安装。装在哪个目录都可以——Vibe Seller 会自己找到它（注册表、开始菜单快捷方式、常见安装位置都会找一遍）。
2. 安装后至少手动启动并登录一次稳卖客户端，确认账号正常、能看到你的店铺列表。之后 Vibe Seller 会自动拉起并自动登录这个客户端（见下面「自动登录」）。

## 创建企业账号（并授权店铺）

稳卖用「企业登录」：企业名称 + 企业用户名 + 企业密码。**手机号登录不行**——那一步有图片验证码，机器过不去，所以只支持企业登录。

1. 在稳卖客户端里用管理员账号进入 **团队管理 → 成员**，创建一个企业子账号。
2. 在 **店铺权限** 里勾选这个子账号可以操作的店铺。子账号只能看到授权给它的店铺——一个都没授权，它在 Vibe Seller 里就一个店铺都列不出来。
3. 记下三样东西：**企业名称**、**企业用户名**、**该用户的密码**。这就是你在 Vibe Seller 里要填的。

## 给店铺绑定设备

稳卖里每个店铺都要绑定一个设备（网络环境）才能打开。没绑定设备的店铺会出现在列表里，但显示为「未绑定设备」、无法选中——去稳卖客户端给这个店铺绑定设备后刷新即可。

另外，店铺的浏览器内核要选 **Chrome**：Firefox 等其他内核的店铺任务打不开，见[店铺要用 Chrome 内核](browsers.md#店铺要用-chrome-内核)。

## 绑定时要填什么

新建店铺时浏览器后端选「稳卖」，和紫鸟在同一个表单里绑定：

1. 点账号栏右侧的「+」，填写三项并保存：

| 字段 | 是什么 |
|---|---|
| 企业名称 | 你的稳卖企业标识 |
| 企业用户名 | 企业下那个子账号的用户名 |
| 企业密码 | 该子账号的密码 |

2. 保存后，Vibe Seller 会用这套企业登录自动登录客户端，并自动加载这个账号能看到的店铺列表。
3. 在「选择店铺...」里挑出这家店对应的那一个，点「创建」。列表显示「店铺名 · 平台」；未绑定设备的店铺是灰的、选不了。

密码加密保存在本机，接口不会把它返回给前端（见下面「凭据存在哪里」）。

## 一台机器只支持一个账号

和悦互联一样，一台机器同一时间只能登录一个稳卖账号，所以账号栏**只有一个「+」**，没有编辑 / 删除——再点「+」填一个新账号，就会**覆盖**原来那个。

如果这台机器上已经绑了稳卖店铺，直接加新账号会被拦下，提示：

> 稳卖一台机器只支持一个账号，请先在设置页面删除所有稳卖店铺，再添加新账号。

要换成另一个稳卖账号：先在「设置 → 店铺」里删掉所有稳卖店铺，再点「+」添加新账号、重新绑定店铺。同一台机器上的所有稳卖店铺都共用这一个账号。

如果稳卖客户端里当前登录的**不是**你保存的这个账号（比如有人手动切换过），绑定和任务会明确报「客户端登录的是另一个账号」，不会自动把别人登出——在稳卖客户端退出登录，或把这里保存的账号改成当前这个，即可恢复。

## 自动登录

客户端退出了、或登录过期了，Vibe Seller 会用你保存的企业登录自动登回去，任务不会因为「没登录」而中断。所以你不用每次手动去登录稳卖客户端——把企业登录配好即可。

## 打开店铺的中间页

稳卖打开一个店铺时，先出现一个「店铺信息」页，要点里面的「打开店铺」按钮才会进入真正的店铺后台。这一步 Vibe Seller 会自动完成，任务和 AI 不需要（也不会）去点它。

## 任务进行中关掉了稳卖

不用手动处理。任务下一次用到浏览器时，Vibe Seller 会自动重新打开稳卖客户端、自动登录，再把这个店铺打开。哪怕你手动打开过这个店铺，也没关系——稳卖给每个店铺内核都开了调试端口，Vibe Seller 会直接接上同一个会话，不会重复开一个。

店铺浏览器被你手动关掉也一样：下次使用会重新打开。任务结束后，Vibe Seller 会正常关闭店铺浏览器，稳卖客户端里看到的「运行中店铺」列表会和实际一致。

## 常见提示 / 报错

| 提示 / 报错 | 含义 / 怎么办 |
|---|---|
| 未登录——请先在稳卖客户端登录，再点「刷新」 | 没配企业登录、或自动登录没成功。确认「+」里填的企业名称 / 用户名 / 密码正确，且客户端能手动登上。 |
| 无法自动启动稳卖客户端——请先手动打开（或确认已安装），再点「刷新」 | Vibe Seller 没找到 / 没能拉起客户端。先手动打开稳卖客户端，或按上面「下载与安装」确认已装好。 |
| 稳卖客户端现在登录的是另一个账号 | 客户端里登录的不是保存的这个企业账号。在稳卖客户端退出登录，或把保存的账号改成当前这个。 |
| 当前店铺未绑定可用设备，无法启动 — 在稳卖客户端给这个店铺绑定设备 | 这个店铺在稳卖里没绑定设备。去稳卖客户端给它绑定设备后重试。 |
| 该店铺使用 Firefox 内核 … only Chromium-kernel stores are supported | 这个店铺在稳卖里用的是 Firefox 内核，没有调试端口，机器没法操作。在稳卖客户端把它切换为 Chromium 内核。 |
| 稳卖一台机器只支持一个账号… | 见上面「一台机器只支持一个账号」。 |
| 不支持的平台 | 稳卖后端目前支持 Windows（原生）和 WSL 两种模式；macOS 验证中，纯 Linux 不可用。 |

## 凭据存在哪里

企业登录（企业名称 / 用户名 / 密码）保存在你本地的 `~/.vibe-seller/data/vibe_seller.db`（SQLite）。密码加密存储，密钥从本机安装派生，只在自动登录那一刻才在内存里解密；接口不会把密码返回给前端。因为一台机器只有一个稳卖账号，这套凭据是机器级的，所有稳卖店铺共用。想看具体加密实现见 [开发者指南](dev-guide.md)。
