# 比特浏览器：配置指南

比特浏览器（BitBrowser）是一款防关联浏览器（[官网](https://www.bitbrowser.net/)，[API 文档](https://doc.bitbrowser.net/)）。绑定后，Vibe Seller 通过它的本地 HTTP API 打开窗口，再通过 CDP（Chrome DevTools Protocol）直接控制店铺页面；客户端没开时会自动拉起。

**比特浏览器后端支持 Windows、macOS，也支持 WSL**。

不用比特浏览器的话，这一页可以跳过。Vibe Seller 还支持其他浏览器，见 [浏览器](browsers.md)。

## 下载与安装

- **Windows**：在 [下载页](https://www.bitbrowser.net/download/) 下载 Windows（64 位）客户端并安装。默认位置是 `C:\Users\<用户名>\AppData\Local\Programs\bitbrowser`；装在其他位置也能被找到。
- **macOS**：在同一下载页下载 macOS（Apple Silicon 或 Intel）客户端，拖进「应用程序」（`/Applications/比特浏览器.app`）。装在其他位置时，在设置里保存客户端路径。

装好后先手动启动并登录一次比特浏览器，确认账号正常、能看到你的浏览器窗口列表。

## 账号与自动登录

在 Vibe Seller 里保存比特浏览器的**账号和密码**（建议用子账号）。登录过期时，Vibe Seller 会通过客户端自己的登录页自动重新登录，任务不会因为「没登录」而中断。密码加密保存在本机（见下面「凭据存在哪里」）。

- 客户端被关掉、被强杀后重新打开，登录状态一般还在；只有登录过期时才需要自动登录。
- **一个比特浏览器账号同一时间只能在一台电脑上登录**：在别的电脑上登录同一个账号，这台就会被踢下线。被踢下线时 Vibe Seller **不会**自动登录（两台电脑会互相踢），会提示你重新登录或确认只在一台电脑上使用。手动重新登录后，普通过期又可以自动登录。
- 如果账号触发了登录验证（短信 / 邮箱 / 二次验证），或连续输错后出现滑块验证，Vibe Seller 不会自动完成，需要你在比特浏览器里手动完成后再重试。
- 子账号也能用：子账号能看到自己创建的窗口，加上主账号授权给它的窗口。列表为空通常说明「没有授权」，不是坏了——找主账号在「员工管理」里给子账号分配窗口权限。
- 免费版可以永久使用 10 个浏览器窗口。

## 绑定时要填什么

新建店铺时浏览器后端选「比特浏览器」：

1. 点账号栏右侧的「+」，填写**比特浏览器账号和密码**并保存（一台机器只保留一个账号；更换账号前要先删除用它创建的所有店铺）。
2. 保存后窗口列表会自动加载。
3. 在「选择窗口...」里挑出这家店对应的窗口（显示为 `序号 + 窗口名称`），点「创建」。

绑定用的是窗口 ID（不是窗口名称），所以在比特浏览器里改窗口名称不影响已绑定的店铺。

## 端口与鉴权：自动读取

比特浏览器的本地接口默认在 `127.0.0.1:54345`，Vibe Seller 通过它读取窗口列表、打开和关闭窗口。接口地址和鉴权开关都在客户端的「系统设置 → Local API」里，Vibe Seller 会**自动从客户端的配置文件读取**：

- 改了「Local API 端口」不用重新绑定，下次连接就会用新端口。
- 打开了「鉴权控制」（Local API Token）也能直接用：Vibe Seller 自动带上令牌，不需要你复制粘贴。

!!! warning "公共网络建议开启「鉴权控制」"
    比特浏览器的本地接口监听所有网卡。如果这台电脑在公共网络里，建议在设置里打开「鉴权控制」，避免局域网里其他设备直接调用你的比特浏览器。

## 打开店铺时的「工作台」标签页

比特浏览器打开一个窗口时，通常会同时打开一个「工作台」标签页（显示 IP、指纹信息）和店铺自己的页面。Vibe Seller 会通过 CDP **自动关掉工作台标签页**、切到店铺页面——你的窗口设置不会被改动，手动在客户端里打开时工作台标签页照常显示。

如果窗口里只有空白页，Vibe Seller 会把这个空白页导航到店铺自己的页面，不会把空白浏览器交给任务。

## 关掉了客户端 / 手动打开过店铺

- **任务中关掉比特浏览器**：不用处理。下一次用到浏览器时，Vibe Seller 会重新拉起客户端，再打开店铺并恢复 CDP 连接。
- **手动在客户端里打开过这个店铺**：任务会直接接管这个已经打开的窗口，不用重新打开。Vibe Seller 通过客户端的运行中窗口列表确认窗口已经打开，再接管它的 CDP 连接，并同样关掉工作台标签页。

## 店铺要用 Chrome 内核

!!! warning "只能使用 Chrome 内核的窗口"
    Vibe Seller 通过 CDP 控制页面，只能控制 Chrome（Chromium）内核的窗口；Firefox 内核的窗口没有这套接口，任务打不开。创建或编辑窗口时，在比特浏览器的「指纹」设置里把内核选成 Chrome。

Firefox 内核的窗口在店铺列表里会**置灰并标注原因**，选中它创建店铺会被拦下。已经绑定的窗口改成 Chrome 后不用重新绑定，再运行一次任务即可。详见 [店铺要用 Chrome 内核](browsers.md#店铺要用-chrome-内核)。

## 常见提示 / 报错

| 界面提示 | 含义 / 怎么办 |
|---|---|
| 未登录——请先在比特浏览器客户端登录（登录一次即可），再点「刷新」。 | 登录过期了。检查设置里的账号密码，或在比特浏览器里手动登录一次。 |
| 比特浏览器未登录且没有保存的账号密码。请在设置里填写比特浏览器账号和密码，或在比特浏览器里手动登录 | 没有保存的凭据可用来自动登录。按「账号与自动登录」一节保存账号和密码，或手动登录一次。 |
| 自动登录没有成功，请手动打开比特浏览器登录一次，然后重试任务 | 自动登录没有成功。手动登录一次，然后重试任务。 |
| 这个比特浏览器账号在另一台电脑登录了，本机已退出。请在比特浏览器里重新登录（或确认只在一台电脑上使用） | 同一账号在另一台电脑上登录，本机被踢下线。请只在一台电脑上使用，再手动登录。 |
| 比特浏览器账号或密码不对，请在设置里重新填写 | 保存的账号或密码不正确。到设置里核对并重新填写。连续输错可能出现滑块验证，需要手动完成。 |
| 需要在比特浏览器里完成登录验证（短信/邮箱/二次验证），完成后重试 | 账号需要登录验证，也可能连续输错后出现了滑块。请在比特浏览器里手动完成验证后再重试。 |
| 无法自动启动比特浏览器客户端——请先手动打开（或确认已安装），再点「刷新」。 | Vibe Seller 没找到 / 没能拉起客户端。先手动打开比特浏览器；如果装在非常规位置，在设置里保存客户端路径。 |
| 请在比特浏览器 → 设置 → Local API 里检查「鉴权控制」，再重试任务。 | 本地接口的鉴权开关和令牌不对。到比特浏览器 → 设置 → Local API 里检查「鉴权控制」的开关状态，然后重试任务。 |
| 这个窗口用的不是 Chrome（Chromium）内核，任务无法打开它；在比特浏览器里把这个窗口的内核切换为 Chrome（指纹 → 内核）后重试 | 窗口用的是 Firefox 等非 Chrome 内核。按提示把内核切换为 Chrome。 |
| 比特浏览器客户端打开了这个店铺，但提示现在用不了。请到比特浏览器客户端里查看这个店铺的状态，处理好后点「重试」。 | 在比特浏览器里查看窗口状态，处理好后点「重试」。 |
| 比特浏览器客户端里找不到这个店铺。请确认这个店铺还在比特浏览器客户端里、当前登录的账号能看到它，然后点「重试」。 | 窗口可能被删除了，或当前账号没有权限。确认窗口还在、且对当前账号可见。 |
| 该登录身份下没有可见窗口——子账号需要主账号在「员工管理」里授权窗口。 | 当前账号名下没有窗口，或没有被授权。见上面「账号与自动登录」里的子账号说明。 |
| 这个浏览器不支持当前系统。 | 比特浏览器后端支持 Windows、macOS，也支持 WSL。 |

## 凭据存在哪里

比特浏览器的**账号和密码**保存在你本地的 `~/.vibe-seller/data/vibe_seller.db`（SQLite）。密码加密存储，密钥从本机安装派生，只在自动登录那一刻才在内存里解密；接口不会把密码返回给前端。

本地接口的端口和令牌从比特浏览器自己的配置文件读取（Windows：`%APPDATA%\BitBrowser\config.json`；macOS：`~/Library/Application Support/BitBrowser/config.json`），Vibe Seller 不另外保存。
