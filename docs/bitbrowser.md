# 比特浏览器：配置指南

比特浏览器（BitBrowser）是一款防关联浏览器（[官网](https://www.bitbrowser.net/)）。绑定后，Vibe Seller 会通过它打开你的店铺执行任务。

**比特浏览器后端支持 Windows、macOS，也支持 WSL**。

## 下载与安装

- **Windows**：在 [下载页](https://www.bitbrowser.net/download/) 下载 Windows（64 位）客户端并安装。默认位置是 `C:\Users\<用户名>\AppData\Local\Programs\bitbrowser`；装在其他位置也可以。
- **macOS**：在同一下载页下载 macOS（Apple Silicon 或 Intel）客户端，拖进「应用程序」。默认位置是 `/Applications/比特浏览器.app`；装在其他位置时，在设置里保存客户端路径。

装好后先手动打开比特浏览器，登录账号，确认能看到你的浏览器窗口列表。

## 账号与自动登录

在 Vibe Seller 里保存比特浏览器的**账号和密码**（建议用子账号）。登录过期时，Vibe Seller 会自动重新登录。密码加密保存在本机。

- **一个比特浏览器账号同一时间只能在一台电脑上登录**。在别的电脑登录同一账号，这台就会被退出；这时 Vibe Seller 不会自动登录，避免两台电脑互相挤下线。
- 短信、邮箱、二次验证或滑块验证需要你在比特浏览器里手动完成。
- 子账号能看到自己创建的窗口，以及主账号授权给它的窗口。列表为空通常是还没授权：请主账号在「员工管理」里分配窗口权限。
- 免费版可以永久使用 10 个浏览器窗口。

## 绑定时要填什么

新建店铺时，浏览器后端选「比特浏览器」：

1. 点账号栏右侧的「+」，填写**比特浏览器账号和密码**并保存。一台机器只保留一个账号；更换账号前要先删除用它创建的所有店铺。
2. 保存后，窗口列表会自动加载。
3. 在「选择窗口...」里选择这家店对应的窗口，点「创建」。

绑定使用窗口 ID，不是窗口名称，所以以后在比特浏览器里改窗口名称不影响已绑定的店铺。

本地接口的端口和鉴权不用配置，Vibe Seller 会自动读取。

!!! warning "公共网络建议开启「鉴权控制」"
    比特浏览器的本地接口监听所有网卡。如果这台电脑在公共网络里，建议在比特浏览器的设置里打开「鉴权控制」，避免局域网里的其他设备调用它。

## 店铺要用 Chrome 内核

!!! warning "只能使用 Chrome 内核的窗口"
    Vibe Seller 只能控制 Chrome 内核的窗口；Firefox 内核的窗口任务打不开。创建或编辑窗口时，在比特浏览器的「指纹」设置里把内核选成 Chrome。

Firefox 内核的窗口在列表里会置灰并标注原因。已经绑定的窗口改成 Chrome 后，不用重新绑定，直接重试任务即可。详见 [店铺要用 Chrome 内核](browsers.md#店铺要用-chrome-内核)。

## 常见提示 / 报错

<details id="login-required">
<summary>未登录——请先在比特浏览器客户端登录（登录一次即可），再点「刷新」。</summary>

登录已过期。检查设置里保存的账号密码，或在比特浏览器里手动登录一次，再点「刷新」。

</details>

<details id="no-credentials">
<summary>比特浏览器未登录且没有保存的账号密码。请在设置里填写比特浏览器账号和密码，或在比特浏览器里手动登录</summary>

按「账号与自动登录」一节保存账号和密码，或在比特浏览器里手动登录一次。

</details>

<details id="auto-login-failed">
<summary>自动登录没有成功，请手动打开比特浏览器登录一次，然后重试任务</summary>

自动登录没有成功。手动登录一次，然后重试任务。

</details>

<details id="device-kick">
<summary>这个比特浏览器账号在另一台电脑登录了，本机已退出。请在比特浏览器里重新登录（或确认只在一台电脑上使用）</summary>

同一账号在另一台电脑上登录，本机被退出。请只在一台电脑上使用这个账号；确认后，在比特浏览器里重新登录，再重试任务。

</details>

<details id="wrong-password">
<summary>比特浏览器账号或密码不对，请在设置里重新填写</summary>

保存的账号或密码不正确。请在设置里重新填写，再重试任务。连续输错可能出现滑块验证，需要手动完成。

</details>

<details id="verification-required">
<summary>需要在比特浏览器里完成登录验证（短信/邮箱/二次验证），完成后重试</summary>

账号需要登录验证，也可能是连续输错后出现了滑块验证。Vibe Seller 不会自动完成验证；请在比特浏览器里手动完成，再重试任务。

</details>

<details id="client-not-running">
<summary>无法自动启动比特浏览器客户端——请先手动打开（或确认已安装），再点「刷新」。</summary>

先手动打开比特浏览器。如果装在非常规位置，在设置里保存客户端路径，再点「刷新」。

</details>

<details id="api-auth">
<summary>请在比特浏览器 → 设置 → Local API 里检查「鉴权控制」，再重试任务。</summary>

到比特浏览器 → 设置 → Local API 里检查「鉴权控制」的开关状态，然后重试任务。

</details>

<details id="kernel">
<summary>这个窗口用的不是 Chrome（Chromium）内核，任务无法打开它；在比特浏览器里把这个窗口的内核切换为 Chrome（指纹 → 内核）后重试</summary>

按提示把窗口内核切换为 Chrome，再重试任务。

</details>

<details id="store-unavailable">
<summary>比特浏览器客户端打开了这个店铺，但提示现在用不了。请到比特浏览器客户端里查看这个店铺的状态，处理好后点「重试」。</summary>

在比特浏览器里查看这个窗口的状态，处理好后点「重试」。

</details>

<details id="store-not-found">
<summary>比特浏览器客户端里找不到这个店铺。请确认这个店铺还在比特浏览器客户端里、当前登录的账号能看到它，然后点「重试」。</summary>

窗口可能被删除了，或当前账号没有权限。确认窗口还在、当前账号能看到它，再点「重试」。

</details>

<details id="no-stores">
<summary>该登录身份下没有可见窗口——子账号需要主账号在「员工管理」里授权窗口。</summary>

请主账号在「员工管理」里给这个子账号分配窗口权限，再刷新列表。

</details>

<details id="unsupported-platform">
<summary>这个浏览器不支持当前系统。</summary>

比特浏览器后端支持 Windows、macOS，也支持 WSL。

</details>

<details id="workbench-tab">
<summary>打开店铺时出现「工作台」标签页</summary>

Vibe Seller 会在任务开始前自动关掉它并切到店铺页面，不用管。

</details>

<details id="client-killed">
<summary>任务中关掉了比特浏览器</summary>

不用处理：下次用到浏览器时会自动重新拉起客户端并打开店铺。

</details>

<details id="hand-opened-profile">
<summary>手动打开过店铺</summary>

任务会直接接管这个已经打开的窗口，不用重新打开；「工作台」标签页也会自动关掉。

</details>

<details id="credentials-storage">
<summary>凭据存在哪里</summary>

账号和密码保存在本机的 Vibe Seller 数据库里，密码加密存储，只在自动登录时解密使用，界面不会显示完整密码。本地接口的端口和令牌由 Vibe Seller 自动读取，不另外保存。

</details>
