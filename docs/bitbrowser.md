# 比特浏览器：配置指南

比特浏览器（BitBrowser）是一款国产防关联浏览器（[官网](https://www.bitbrowser.net/)，[API 文档](https://doc.bitbrowser.net/)）。绑定后，Vibe Seller 会通过它的本地接口打开你的店铺执行任务；客户端没开时会自动拉起。

**比特浏览器后端支持 Windows，也支持 WSL**。macOS 版客户端存在，但 Vibe Seller 暂未对接。

不用比特浏览器的话，这一页可以跳过。Vibe Seller 还支持其他浏览器，见 [浏览器](browsers.md)。

## 下载与安装

1. 打开官网 [下载页](https://www.bitbrowser.net/download/)，下载 Windows（64 位）客户端并安装。默认装在 `C:\Users\<用户名>\AppData\Local\Programs\bitbrowser`；装在其他位置也能被找到。
2. 安装后**手动启动并登录一次**比特浏览器，确认账号正常、能看到你的店铺（浏览器窗口）列表。

## 账号与自动登录

在 Vibe Seller 里保存比特浏览器的**账号和密码**（建议用子账号），登录过期时 Vibe Seller 会自动重新登录，任务不会因为「没登录」而中断。密码加密保存在本机（见下面「凭据存在哪里」）。

- 客户端被关掉、被强杀后重新打开，登录状态一般还在；只有过期时才会自动登录。
- **一个比特浏览器账号同一时间只能在一台电脑上登录**：在别的电脑上登录同一个账号，这台就会被踢下线。被踢下线时 Vibe Seller **不会**自动登录（两台电脑会互相踢），会提示你重新登录或确认只在一台电脑上使用。
- 如果账号触发了登录验证（短信 / 邮箱 / 二次验证），Vibe Seller 无法自动完成，会提示你在比特浏览器里手动完成后再重试。
- 子账号也能用：子账号能看到自己创建的窗口，加上主账号授权给它的窗口。列表是空的通常说明「没有授权」，不是坏了——找主账号在「员工管理」里给子账号分配窗口权限。
- 免费版可以永久使用 10 个浏览器窗口。

## 绑定时要填什么

新建店铺时浏览器后端选「比特浏览器」：

1. 点账号栏右侧的「+」，填写**比特浏览器账号和密码**并保存（一台机器只保留一个账号；再点「+」会覆盖原来的）。
2. 保存后店铺列表会自动加载（客户端登录着即可）。
3. 在「选择店铺...」里挑出这家店对应的窗口（显示为 `序号 + 窗口名称`，如 `#1 test1`），点「创建」。

绑定用的是窗口 ID（不是窗口名称），所以在比特浏览器里改窗口名称不影响已绑定的店铺。

## 端口与鉴权：自动读取

比特浏览器的本地接口地址和鉴权开关，都在它自己的设置里（系统设置 → Local API）。Vibe Seller 会**自动从客户端的配置文件读取**：

- 改了「Local API 端口」不用重新绑定，Vibe Seller 下次连接就会用新端口。
- 打开了「鉴权控制」（Local API Token）也能直接用：Vibe Seller 自动带上令牌，不需要你复制粘贴。

> 小提示：比特浏览器的本地接口监听所有网卡。如果这台电脑在公共网络里，建议在设置里打开「鉴权控制」，避免局域网里其他设备直接调用你的比特浏览器。

## 打开店铺时的「工作台」标签页

比特浏览器打开一个窗口时，会同时打开一个「工作台」标签页（显示 IP、指纹信息）和店铺自己的页面。Vibe Seller 会在任务开始前**自动关掉工作台标签页**、切到店铺页面——你的窗口设置不会被改动，手动在客户端里打开时工作台标签页照常显示。

## 关掉了客户端 / 手动打开过店铺

- **任务中关掉比特浏览器**：不用处理。下一次用到浏览器时，Vibe Seller 会重新拉起客户端（它会自动回到登录状态），再打开店铺。比特浏览器的店铺窗口会随客户端一起退出，不会留下需要清理的后台进程。
- **手动在客户端里打开过这个店铺**：如果 Vibe Seller 没有这个店铺的旧会话，任务会直接接管这个已打开的窗口（同一个调试端口），并同样关掉工作台标签页。但如果 Vibe Seller 还留着一个旧会话（比如上一次任务结束后窗口被手动关过），接管前会先把窗口关掉再重新打开——手动打开的窗口和里面的页面状态会丢失。

## 店铺要用 Chrome 内核

和所有防关联浏览器一样，**Vibe Seller 只能控制 Chrome 内核的窗口**；Firefox 内核的窗口没有调试接口，无法驱动。比特浏览器里创建 / 编辑窗口时，在「指纹」里把内核选成 Chrome。

Firefox 内核的窗口在店铺列表里会**置灰并标注原因**，选中它创建店铺会被拦下。已经绑定的窗口改了内核后不用重新绑定，再运行一次任务即可。详见 [店铺要用 Chrome 内核](browsers.md#店铺要用-chrome-内核)。

## 常见提示 / 报错

| 界面提示 | 含义 / 怎么办 |
|---|---|
| 未登录——请先在比特浏览器客户端登录，再点「刷新」 | 客户端登录过期了，且没有保存的账号密码（或自动登录没有成功）。检查设置里的账号密码，或在比特浏览器里手动登录一次。 |
| 这个比特浏览器账号在另一台电脑登录了，本机已退出…… | 同一账号在另一台电脑上登录，本机被踢下线。Vibe Seller 不会自动登录（两台电脑会互相踢）。请在比特浏览器里重新登录，或确认只在一台电脑上使用。 |
| 比特浏览器账号或密码不对，请在设置里重新填写 | 保存的账号密码登录失败。到设置里核对并重新填写。 |
| 需要在比特浏览器里完成登录验证（短信/邮箱/二次验证），完成后重试 | 账号在新设备上登录需要验证。在比特浏览器里手动完成验证后再重试任务。 |
| 无法自动启动比特浏览器客户端——请先手动打开（或确认已安装），再点「刷新」 | Vibe Seller 没找到 / 没能拉起客户端。先手动打开比特浏览器；如果装在非常规位置，在设置里保存客户端路径。 |
| 请在比特浏览器 → 设置 → Local API 里检查「鉴权控制」，再重试任务。 | 本地接口的鉴权开关和令牌不对。到比特浏览器 → 设置 → Local API 里检查「鉴权控制」的开关状态，然后重试任务。 |
| 这个窗口用的不是 Chrome（Chromium）内核…… | 窗口用的是 Firefox 等非 Chrome 内核。在比特浏览器里把该窗口的内核改成 Chrome（见上一节）。 |
| 打开失败：内核更新失败，请重新启动客户端再打开 | 比特浏览器下载内核失败（多见于 Firefox 内核）。重启比特浏览器让它重新下载，再运行任务。 |
| 打开失败：服务调用成功，但没有找到相应数据 | 窗口在比特浏览器里被删除了，或当前登录的账号看不到它。确认窗口还在、且对当前账号可见。 |
| 该登录身份下没有可见店铺 | 当前登录的账号（或子账号）名下没有窗口，或没有被授权。见上面「登录一次就够了」里的子账号说明。 |
| 不支持的平台 | 比特浏览器后端只在 Windows 和 WSL 上可用（Windows，也支持 WSL）。 |

## 凭据存在哪里

比特浏览器的**账号和密码**保存在你本地的 `~/.vibe-seller/data/vibe_seller.db`（SQLite）。密码加密存储，密钥从本机安装派生，只在自动登录那一刻才在内存里解密；接口不会把密码返回给前端。本地接口的端口和令牌从比特浏览器自己的配置文件（`%APPDATA%\BitBrowser\config.json`）实时读取，Vibe Seller 不另外保存。
